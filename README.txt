CHRISTMAS SCOOP MYSTERIES | THREE-BUILDING CHECKPOINT

GitHub Pages publishing:
1. Open https://github.com/emcgeek314/christmas-scoop-mysteries
2. Choose Add file > Upload files.
3. Upload index.html and village.png from this ZIP into the ROOT of the repository (not a subfolder). Commit changes.
4. In Settings > Pages, select Deploy from a branch, main, /(root), Save (if not already enabled).
5. Visit https://emcgeek314.github.io/christmas-scoop-mysteries/ after Pages deploys.

IMPORTANT: This is a VISUAL PROTOTYPE, not the finished advent calendar. All three dates are available for testing. It stores state only in the current browser (localStorage), not across devices. The actual flavors are embedded in public HTML and therefore are NOT secret; do not use this build as the live December surprise. Final build needs protected date-gated flavor data and synced storage.

CHECKPOINT: test each marker, reveal, glow, notes, snowflake rating, Buy Again, reset, and print book on iPhone. Masks are approximations, and must be visually inspected before approval.
